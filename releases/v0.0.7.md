## Highlights ⭐️

* **The site theme takes the site's layouts**: The sebastienrousseau theme gets the column layouts and type scale of sebastienrousseau.com, ships the hero portrait those layouts use, and stays inside a 320 px viewport.
* **Accessible names match what is on screen**: Brand links, copy buttons and search triggers in 18 themes now have an accessible name that contains their visible text (WCAG 2.5.3). axe-core 4.14 began reporting these in 0.0.6, which had turned the build on `main` red.
* **A tighter CI**: Every action is pinned to a commit SHA, the Pages artifact is uploaded before any npm-installed tool runs, a crates.io version string is validated before CI uses it, and the generator pin moves to ssg 0.0.72 with local builds held to it.
* **Unit tests for the HTML rewriters**: `make test` runs first, and its first case pins the fix that re-bases `imagesrcset`, so the site theme's hero preload no longer points at files that do not exist.
