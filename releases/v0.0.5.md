## Highlights ⭐️

* **The diagnostic theme is passmcp**: Scout is renamed after the tool it showcases, with its layouts, gallery card and download names following.
* **sebastienrousseau.com ships as a theme**: The production theme of the research site joins the gallery as a site-tier theme. One shell replaces twelve 213 KB flat layouts, and `tools/flatten.py` reproduces the site's `_layouts/` byte for byte, which is the gate it is held to.
* **Site themes declare their own origins**: `theme.toml` gains `tier = "site"` and `allowed_origins`, so the no-third-party scan treats a live site's own CDN, form and embed hosts as first party while every undeclared host still fails.
* **The site theme's demo resolves under its gallery path**: a site-tier theme keeps root-absolute links, so the showcase build re-bases them onto `/<theme>/` (`scripts/rebase_links.py`) instead of the templates carrying a prefix, and `assets/_root/` publishes files a layout loads from a fixed root path. The demo ships every page its chrome links to, in both locales.
* **The site theme meets every gallery gate**: the three-state mode control, 44 px targets, 320 px reflow, AAA contrast, zoom and text-spacing, print, forced colours, composition and focus suites all pass on the sebastienrousseau theme, and the live site adopts the design through the theme.
