## Highlights ⭐️

* **All 22 themes on Skeletonic CSS 3.0.0**: Every theme is built on a locally compiled Skeletonic CSS 3.0.0 and validated with SSG 0.0.63.
* **One colour-mode control everywhere**: Every theme has the same light, dark and system control, and the same linked footer credit for SSG and Skeletonic CSS.
* **Accessibility fixes across the catalogue**: Heading spacing is proportional again, Prism's imagery is full-width at every size, Quill's and Stablo's footer focus no longer overlaps, and disclosure summaries no longer contain interactive elements.
