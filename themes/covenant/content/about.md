## A decisive visual language

Black, warm white and red form a strict grid inspired by institutional
editorial design. Architectural forms are created in CSS and remain purely
decorative, so no meaning disappears when presentation is removed.

## Responsible performance communication

Real deployments should distinguish unrealised value from realised proceeds,
identify reporting periods, explain methodology and place risk beside return.
This theme does not provide investment or legal advice.

## Accessible by design

The palette targets AAA text contrast in both schemes. Keyboard focus, target
size, heading order and responsive reflow are enforced by repository gates.
