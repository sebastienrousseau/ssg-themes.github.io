jspassgen is an open-source cryptographic password and passphrase generator theme
engineered for zero-trust security workflows. It brings high-assurance entropy estimation,
EFF Diceware wordlists, and strict Content Security Policy enforcement to Static Site Generator.

Traditional web-based password generators frequently embed third-party analytics,
ad trackers, and remote CDNs that violate the zero-trust security posture required
for credential management. jspassgen eliminates every remote dependency, providing
a standalone, self-hosted web console and documentation site that functions entirely offline.

The theme implements WCAG 2.2 AAA colour token standards across both dark and light
modes, supports full internationalization, and exposes structured schemas optimized
for both human security officers and automated AI verification agents.
