# Changelog — Voxt

All notable changes to this theme. Format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/); versions follow [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [0.0.1] — 2026-08-29

Initial release of the Voxt theme for Static Site Generator (SSG).

### Added

- Single-page developer and AI tools showcase layout with high-contrast IDE dock preview.
- Dynamic dark/light mode switching with CSS custom properties and instant storage caching.
- Zero-trust security model: strict CSP, zero external CDN scripts, subresource integrity.
- Typed frontmatter validation schema (`content.schema.toml`).
- Responsive layouts tested down to 320px viewport widths with WCAG AAA contrast tokens.
