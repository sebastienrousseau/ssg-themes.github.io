# Sebastien Rousseau Theme (`themes/sebastienrousseau`)

An editorial, research paper, and knowledge hub SSG theme benchmarked against [sebastienrousseau.com](https://sebastienrousseau.com).

## Key Features
- **Editorial Typography & Newsreader Serif:** High-legibility serif headline typography paired with modern UI elements.
- **Research & Papers Layouts:** Tailored templates for technical papers, ISO 20022 reports, applied AI articles, and projects.
- **Security & SRI Hardening:** CSP hash compilation and Subresource Integrity verification.
- **WCAG 2.1 AAA Compliant:** Accessible contrast ratios and full keyboard navigation.

## Layouts Available
- `index.html` - Homepage with Editorial Grid & Hero.
- `page.html` - Generic article/page layout.
- `articles.html` - Article directory layout.
- `papers.html` - Whitepaper & research archive layout.
- `project.html` - Project showcase layout.
- `contact.html` - Contact page layout.
