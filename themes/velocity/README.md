# Kaishi Theme (`themes/kaishi`)

The iconic starter template for Shokunin Static Site Generator (`ssg`).

## Key Features
- **Sleek Product & Starter Landing:** Modern hero, features grid, call to action.
- **Fast Build Speed:** Minimal CSS footprint, ultra-fast static compilation.
- **Responsive Layouts:** Full mobile navigation and dark/light support.

## Layouts Available
- `index.html` - Product/starter homepage.
- `features.html` - Feature showcase page.
- `contact.html` - Contact page.
- `thank-you.html` - Confirmation page.
