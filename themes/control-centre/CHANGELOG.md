# Changelog

## 1.0.0 - 2026-10-17

- Added the app shell: sidebar navigation that becomes a disclosed drawer
  below 64rem, and a top bar with search, language and colour mode.
- Added the status ring with agent and server lists either side, flows drawn
  in each entry's severity colour, and a legend that states each count.
- Added KPI tiles, a critical-finding banner, dashboard panels, severity
  pills and scrollable evidence tables, all filled from front matter and
  Markdown in English and French.
- Added a five-level severity palette held to WCAG AAA in light and dark.
