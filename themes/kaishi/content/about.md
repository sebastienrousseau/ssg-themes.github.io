# About Kaishi

Kaishi is a minimalist, high-performance static site starter template engineered for speed, simplicity, and accessibility.

## Core Pillars
1. **Lightweight Assets:** Zero framework overhead, minimal CSS, instant render times.
2. **Accessible by Default:** WCAG 2.1 AAA contrast compliance and full screen reader navigation.
3. **Rust Compiler Integration:** Native compilation with Shokunin Static Site Generator (`ssg`).
