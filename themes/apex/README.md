# Portfolio Theme (`themes/portfolio`)

A high-impact executive portfolio and leadership theme for Static Site Generator (`ssg`). Inspired by top recruiter-magnet digital portfolio designs.

## Key Features
- **Executive Hero & Metrics Dashboard:** Quantifiable ROI metrics and value proposition.
- **Recruiter Assessment Matrix:** Comparison grid for evaluating executive leadership excellence.
- **Case Study & Project Templates:** Structured layouts for enterprise transformations.
- **Thought Leadership & Frameworks:** Dedicated methodology and whitepaper layouts.
- **100% British English & AAA Accessibility:** Screen reader optimization, WCAG 2.1 AAA contrast, keyboard navigation.
- **Dark & Light Mode:** System preferences auto-detection with manual persistent toggle.

## Layouts Available
- `index.html` - Homepage with Hero, Metrics, Matrix, and Case Studies.
- `page.html` - Standard content page.
- `project.html` - Detailed project / case study page.
- `frameworks.html` - Methodology and framework page.
- `about.html` - Biography & career history timeline.
- `contact.html` - Executive contact form and details.
