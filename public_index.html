What each gate checks

Continuous integration gates and what each one asserts
GateAsserts
Contrast Text token pairs at 7:1 (WCAG 1.4.6, AAA); borders and focus ring at 3:1 (1.4.11) — in both light and dark
Structure Manifests agree, screenshots meet registry sizes, no third-party host appears in any theme source
Page weight Every page under 20 KB gzipped including its CSS and JS; zero third-party subresources
Accessibility The generator's report shows 0 issues, and axe-core passes wcag22aa
Generator audit JSON-LD, hreflang, CSP and SRI, HTML5, broken links, Open Graph, feeds, search index

Getting started

Copy a theme, set your site name and base URL in ssg.toml, and build. Requires ssg 0.0.49 or later. Each theme's README documents its layouts, front-matter contract and token system.
